# nightvision
Night Vision is a "planetarium" program written in Java

Night Vision is a "planetarium" program that will display the heavens
from any location on earth. Viewing options allow the user to control
which sky objects to display, which font to use, and manipulation of
various star parameters. Time may be set to run at multiple speeds,
including backwards. Star charts may be printed.

Night Vision is written in Java, allowing it to run on all major
desktop systems (includes PCs, Macs, Linux, ...). It has been designed
to be readily translatable into other languages.

Features
- View sky from 10BC to 3000AD
- View solar system from any angle
- Stars up to 11th magnitude (over a million)
- Print star charts

To compile and run the source files, follow the instructions in readme.txt

Pre-compiled installable packages (which embed Java and don't require a
separate Java installation) are available at:
https://sourceforge.net/projects/nightvision
